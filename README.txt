🐷 КОПИЛКА — личный трекер дохода и накоплений
════════════════════════════════════════════

Работает прямо в браузере: без сервера, без регистрации, без слежки.
Все данные хранятся только на твоём устройстве.

🔗 Открыть: https://kira0784.github.io/Kopilka/
📲 На телефоне: меню Chrome → «Добавить на главный экран» —
   станет приложением и будет работать даже без интернета.

──────────────────────────────
ЧТО ВНУТРИ
──────────────────────────────

💰 ДОХОД
   • Записи смен: дата, часы, заработок, заказы и чаевые 💛
   • Калькулятор дохода: ставка в час, средняя смена, итоги по неделям
   • 🎲 События курьерки: «доставь N заказов — получи приз»,
     с дедлайнами, ✏️ правкой и архивом
   • 💼 «Бонусы, если закрыть все события» — сумма спрятана
     спойлером, как скрытое слово в Telegram (тапни — раскроется)
   • 🔔 Напоминание записывать смены

🐷 КОПИЛКА
   • Главная цель, баланс свинки и новые цели
   • Уровень копителя, ачивки и стрик дней
   • Советы студенту

🐔 КОРМ
   • Своя курица: выдавай корм и следи за статусом
   • 🗂 Секретная папка под PIN-кодом: личные файлы
     с шифрованием + ☁️ облако через свой GitHub-токен

⏱ НАКРУТКА
   • Часы Steam = реальные + накрученные, прогресс по каждой игре

💾 БЭКАП
   • Скачай резервную копию (JSON) — все записи, цели, события
     и секретная папка в одном файле. Загрузка обратно возвращает
     всё на место — перенос на новый телефон за минуту.
