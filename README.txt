Копилка — загрузка на GitHub и свой сайт (бесплатно)
=====================================================

ШАГ 1. АККАУНТ
Зайди на github.com (с телефона или компа) -> Sign up:
логин (латиницей), e-mail, пароль. Подтверди e-mail из письма.

ШАГ 2. СОЗДАТЬ РЕПОЗИТОРИЙ
Справа вверху нажми «+» -> New repository.
  Name: kopilka (можно любое название латиницей)
  Выбери Public (обязательно для бесплатного сайта)
Нажми зелёную кнопку Create repository.

ШАГ 3. ЗАГРУЗИТЬ ФАЙЛЫ
На открывшейся странице нажми ссылку «uploading an existing file»
(или Add file -> Upload files). Перетащи СРАЗУ ОБА файла:
  index.html
  sw.js
Дождись, пока оба появятся в списке, и нажми зелёную кнопку
«Commit changes». Готово — файлы в интернете!

ШАГ 4. ВКЛЮЧИТЬ САЙТ (делается один раз)
В репозитории открой Settings -> в меню слева Pages.
  Source: Deploy from a branch
  Branch: main, папка / (root) -> Save
Подожди 1-2 минуты и обнови страницу — вверху появится зелёная
надпись с адресом твоего сайта:
  https://ТВОЙ_ЛОГИН.github.io/kopilka/
Открой его в браузере телефона -> «Установить приложение» —
и Копилка станет приложением с этим адреса.

КАК ОБНОВЛЯТЬ В 1 КЛИК (когда придёт новая версия)
1) Открой свой репозиторий на github.com
2) Add file -> Upload files
3) Перетащи новый index.html (он заменит старый)
4) Commit changes — сайт обновится сам через минуту.
Приложение на телефоне подхватит обновление при следующем открытии.
Файл sw.js не трогай — он уже правильный.

ПЕРЕНОС ДАННЫХ (если уже есть записи в старой Копилке)
1) В СТАРОЙ Копилке: нажми экспорт/бэкап — скачается json-файл.
2) На НОВОМ сайте: импортируй этот файл — все записи вернутся.
Данные хранятся в браузере и привязаны к адресу сайта, поэтому
со старого адреса (файл с телефона) сами они не перенесутся.

ВАЖНО
- Оба файла (index.html и sw.js) лежат в корне репозитория, РЯДОМ.
- Не переименовывай и не удаляй их — обновляй только заменой.
- Адрес сайта менять нельзя после установки приложения на телефон
  (иначе придётся заново «Установить приложение» с нового адреса).
