🗂 Секретная папка

Чтобы попасть в Секретную папку, введи ключ шифрования. Забыл его? Жми «🗝 Показать ключ» ниже — секретное меню откроется внизу вкладки «Накрутка» (пока курица жива, меню открывается и 4 тапами по ней).
забыл ключ — покажу
Здесь лежат любые файлы: txt, word, фото, видео и т.д. Каждый файл шифруется твоим ключом перед загрузкой — на GitHub он попадает уже зашифрованным. Один файл — до 90 МБ (жёсткий лимит GitHub — 100 МБ на файл, больше он не хранит вообще, так что видео на сотни МБ сначала сожми).
Файлы будут загружаться в закрытый репозиторий GitHub. Заведи для них новый (как Kopilka-backup, только Private): в токене должно быть право доступа и к этому репозиторию — «Contents: Read and write».

📲 Установить Копилку как приложение

Android (Chrome):

  1. Меню ⋮ справа вверху
  2. «Добавить на главный экран» / «Установить приложение»
  3. Подтверди — иконка 🐷 появится на рабочем столе

iPhone (Safari): «Поделиться» → «На экран „Домой“».

На сайте рядом с index.html должен лежать файл sw.js — он включает кнопку «Установить приложение» и офлайн-режим.
Нет своего сайта? Перетащи оба файла в папке на netlify.com/drop — получишь ссылку и сможешь установить приложение.
«Приложение» — это тот же файл: любые обновления index.html сразу появляются и на сайте, и в приложении. Данные хранятся в браузере телефона и никуда не пропадают.
