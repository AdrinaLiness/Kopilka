# 🐷 Копилка — трекер доходов и накоплений

Бесплатное приложение для студентов и всех, кто копит на мечту.
Записывай смены и чаевые, выполняй события как бонусы в курьерке, расти
в уровнях и корми курицу. Всё работает прямо в браузере: без регистрации,
без интернета, данные не покидают твоё устройство.

**👉 Открыть приложение: [adrinaliness.github.io/Kopilka](https://adrinaliness.github.io/Kopilka/)**

## 1. Как установить

Приложение — PWA: ставится на главный экран телефона или компьютера
и дальше работает как обычное приложение, в том числе без интернета.
Или скачай готовое **APK-приложение** — см. раздел [12. Android-приложение](#12-android-приложение-apk).

### На телефоне (Android / iOS)

1. Открой [приложение](https://adrinaliness.github.io/Kopilka/) в Chrome (Android) или Safari (iPhone).
2. Нажми **«Установить приложение»** прямо в Копилке — вкладка «💰 Доход»,
   блок **🔔 Напоминание и 📲 приложение**. Браузер сам предложит добавить иконку.
3. Либо вручную: Chrome → меню ⋮ → **«Установить приложение» / «Добавить на главный экран»**,
   Safari → кнопка «Поделиться» → **«На экран “Домой”»**.

### На компьютере

1. Открой приложение в Chrome или Edge.
2. В адресной строке справа появится иконка установки — кликни её
   (или меню ⋮ → **«Установить Копилку»**).

После установки Копилка запускается с иконки, открывается в своём окне
без адресной строки и работает офлайн.

### Напоминания

В том же блоке можно включить ежедневное напоминание — в выбранное время
придёт уведомление «🐷 Копилка — отметь день!». Клик по уведомлению
открывает приложение.

## 2. Вкладка «💰 Доход»

Главный экран: здесь ты каждый день отмечаешь работу и видишь, как идёшь к цели.

### Запись дня

Кнопка **«➕ Добавить день»** — заполни дату, часы, заработок и заказы.
Кнопки-ускорители: **«Как вчера»** (копирует прошлую смену), быстрые плюсы
**«+1 ч», «+5 ч», «+100 ₽», «+500 ₽»**. В записи учитываются чаевые
и подарки — они попадают в отдельную категорию.

### Что показывает вкладка

| Блок | Что внутри |
| --- | --- |
| 🎯 Цель | Главная цель (например, 100 000 ₽), дедлайн, недельный план, общий прогресс |
| 📊 Общий прогресс | Заработано всего, дней работал, средне в день, 🔥 стрик (дней подряд) |
| 📈 Динамика по дням | График заработка — видно удачные и слабые дни |
| 📊 Тренд | Эта неделя против прошлой: растёшь или отдыхаешь |
| 🔮 Прогноз | Сколько накопишь к дедлайну, если продолжишь в том же темпе |
| 🧮 Калькулятор дохода | Прикинь заработок за смену до записи |
| 📆 План по месяцам | Сколько нужно зарабатывать каждый месяц, чтобы успеть к дедлайну |
| 📅 План/факт по неделям | План недели против факта — таблица с остатками |
| ⭐ Лучшие дни недели | Какой день приносит больше всего денег |
| 🗂 Категории дохода | Обычные заказы, чаевые, бонусы — разложено по полочкам |
| 🎁 Подарки и разовые акции | Отдельный список подаренных денег и акций |
| 📝 Все записи | Полная таблица со всеми днями, редактирование и удаление |

## 3. Вкладка «🐷 Копилка»

Игровая часть: накопления превращаются в прокачку персонажа.

* **🏁 Главная цель** — на что копишь и сколько уже отложено.
* **🎮 Уровень копителя** — растёт от общего заработка (см. раздел 7).
* **🐷 Баланс копилки** — общая сумма накоплений.
* **➕ Новая цель** — список желаний с эмодзи: 🎧 наушники, 🎮 приставка,
  👟 кроссовки и любые свои. Отмечай выполненные — увидишь прогресс по каждой.
* **🏅 Ачивки** — 10 достижений: от «Первой тысячи» до «Копилки-профи».
* **🗂 Секретная папка 🔐** — личное хранилище файлов (подробности ниже).
* **💡 Советы студенту** — встроенная шпаргалка по экономии:
  * 🎯 **Правило 24 часов** — захотел купить, подожди день;
  * 🐷 **Сначала отложи** — зарплата → копилка → остаток тратим;
  * 🎁 **Подарки не тратят** — всё подаренное сразу в копилку;
  * 🍳 **Еда из дома** — экономит ~2000 ₽/мес;
  * 🔍 **Студ. скидки** — спрашивай везде, бывает до −50%;
  * 💡 **Лайфхак** — переводи цену цели в часы работы: умножь часы на свою ставку.

### 🔐 Секретная папка

Личное хранилище файлов, защищённое ключом шифрования — живёт здесь,
на вкладке «Копилка».

* **Где взять ключ:** жми **«🗝 Показать ключ»** в окне входа в папку —
  секретное меню с ключом появится внизу вкладки «Накрутка». Запиши ключ
  в надёжное место: без него зашифрованные файлы не прочитать.
* **Что можно хранить:** любые файлы — txt, word, фото, видео. Один файл —
  до 90 МБ (жёсткий лимит GitHub — 100 МБ на файл).
* **Как это работает:** каждый файл шифруется твоим ключом ещё на телефоне —
  в облако он попадает уже зашифрованным и хранится в закрытом репозитории.
* Кнопки: **🔓 Открыть папку**, **➕ Добавить файлы**, скачивание и удаление.

## 4. Вкладка «🐔 Корм»

Виртуальный питомец, который следит за твоей стабильностью.

* Один **«🍗 Выдать корм»** живёт **21 день** по умолчанию — при выдаче можно
  указать своё число дней (1–365).
* Карточка показывает: статус в %, когда корм закончится, сколько дней осталось.
* **📋 История корма** — таблица: дата, до какого числа действует. Дату «действует
  до» можно подправить прямо в таблице (✏️), если корм реально закончится
  раньше или позже стандартного срока — например, под реальный CS2-питомец.
* **📊 Статистика** — всего корма выдано, дней покрыто, сколько курица уже прожила.

### Конец курицы 🌤

У курицы, как у всего живого, есть финал — и он настоящий:

* **Корм закончился** — истёк последний корм, и курица уходит:
  вкладка «Корм» исчезает из приложения сразу же, вместе с ней.
* **Прожила ~140 дней** (20 недель с первого корма — столько обещали Valve) —
  курица уходит на пенсию с почестями, вкладка закрывается так же.

Уход финальный — прежняя курица не возвращается. Не грусти: Секретная папка
никуда не девается — она живёт на вкладке «🐷 Копилка» (раздел 3),
а вся статистика остаётся на месте.

#### 🪦 Памятник (остаётся навсегда)

Курица уходит, но не исчезает бесследно: в самом конце вкладки **«🐷 Копилка»**
стоит тихий памятник — одна приглушённая строка в рамке, которая ничего
не перекрывает и не мешает.

* **Тап по строке** — эпитафия: даты жизни, сколько дней прожила,
  сколько корма получила за всю жизнь и скольких дней хватило корм.
* **4 быстрых тапа** по памятнику — открывают то же секретное меню с ключом
  шифрования, что раньше открывалось 4 тапами по живой курице.
* Памятник вечный: стоит, пока курицы нет. Заведёшь новую (снова выдашь корм) —
  вкладка «Корм» вернётся, а памятник тихо уберётся сам.

## 5. Вкладка «⏱ Накрутка»

Счётчик игрового времени в Steam: ставишь план по часам и честно (или не очень)
его набираешь.

* **🎮 Добавить игру** — имя игры, реальное время, целевое.
* Кнопки **«+1 ч» / «+5 ч»** — добавляй наигранные часы.
* **📊 Общий прогресс накрутки** — план часов, накручено, осталось, процент.
* **Суммарно часов в Steam** — общий счётчик по всем играм.

## 6. События курьерки

Мини-челленджи в стиле бонусов доставок: «доставь N заказов — получи приз».

* **🎯 Создать событие** — цель (например, 30 заказов), бонус
  (например, +1500 ₽ или шаурма), дата начала и дедлайн (или ∞ без дедлайна).
* **🎲 Сгенерировать** — приложение само придумает событие с реальной целью
  на основе твоей статистики.
* Прогресс считается по записям за период события — с даты «Действует с»
  по дедлайн включительно. Заказы вводи в форме «Добавить день» или впиши
  задним числом в столбик 🛵 таблицы «Все записи».
* Выполнил — **конфетти 🎉** и забирай бонус. Бонусы за все закрытые события
  суммируются отдельной строкой.
* Активное событие можно поправить кнопкой ✏️ (меняй любые поля) или удалить 🗑.
  Поднял цель выше достигнутой — событие вернётся в работу; продлил дедлайн
  просроченного — оживёт.
* 💼 Строка **«Бонусы, если закрыть все события»** — суммарный куш сверху.

## 8. Данные и приватность

* **Всё хранится только у тебя.** Записи, цели, события и файлы живут
  в хранилище браузера (localStorage) на твоём устройстве. Ни один байт
  не отправляется на сервер — приложение вообще не имеет своего сервера.
* **Без регистрации.** Никаких аккаунтов, почт и паролей. Привязки
  к устройству нет: данные остаются в браузере, где ты их завёл.
* **Офлайн.** После установки приложение открывается и работает
  без интернета (service worker кэширует всё необходимое).
* **Облачные копии — только по твоей команде** и только в твой личный
  закрытый репозиторий GitHub, зашифрованные (см. раздел 9).
* Тёмная тема 🌙 и звук 🔊 переключаются в шапке, выбор запоминается.

## 9. Резервные копии

Блок **«💾 Резервные копии»** на вкладке «💰 Доход».

### 🔐 Зашифрованная резервная копия (рекомендуется)

1. Придумай **код из 4 цифр** — им зашифруются копии.
   Код нигде не хранится: без него копии не прочитать. Запиши его!
2. **💾 Сохранить копию** — скачается зашифрованный файл.
3. **☁️ Копия в GitHub** — копия уйдёт в твой закрытый репозиторий.
   Понадобится токен: github.com → Settings → Developer settings →
   Personal access tokens → сгенерируй и вставь в настройках Копилки.
4. **📥 Загрузить файл** — восстановление из копии на новом устройстве.

### 📲 Перенос на новый телефон

Старый телефон: сделай 🔐 копию → новый телефон: открой Копилку →
«📥 Загрузить файл» → введи код → все данные на месте.

## 10. Важно про данные

Внимательно прочитай перед использованием.

1. **Данные живут в браузере.** Очистка данных сайта в настройках браузера
   удалит все записи, цели и историю корма. Чистишь куки — смотри, что чистишь.
2. **Делай копии.** Одно нажатие «💾 Сохранить копию» раз в пару недель
   спасает годы статистики. Хранить копии лучше в двух местах: файл + облако.
3. **Код из 4 цифр не восстанавливается.** Он нигде не хранится — ни в копии,
   ни на устройстве. Забыл код — зашифрованную копию не открыть ничем.
4. **Ключ Секретной папки тоже не восстанавливается.** Запиши его в надёжное
   место до того, как зальёшь туда первые файлы.
5. **При смене адреса сайта данные не переезжают сами.** Хранилище привязано
   к адресу: переезжай через «🔐 копию → 📥 загрузить».
6. **Уведомления** работают, пока приложение установлено. Если напоминания
   пропали — открой блок «🔔 Напоминание» и включи заново.

## 11. Технологии

* **HTML + CSS + JavaScript** — всё в одном файле `index.html`, ноль зависимостей
  и сборки: открыл — работает.
* **PWA + Service Worker** (`sw.js`) — установка на устройство, офлайн-работа,
  уведомления.
* **localStorage** — хранение всех данных на устройстве.
* **Web Crypto (AES)** — шифрование резервных копий и файлов Секретной папки.
* **GitHub API** — облачные копии и хранилище файлов в твоём закрытом репозитории.
* **GitHub Pages** — хостинг приложения.

## 12. Android-приложение (APK)

Хочешь по-настоящему обычное приложение — с иконкой на рабочем столе, как
из магазина? В папке [`ANDROID/`](ANDROID/) лежит готовый `KOPILKA-v1.4.apk`:

* тот же интерфейс: доход, копилка, курица 🐔, накрутка, уровни, секретная
  папка — в отдельной иконке со свинкой, без браузера;
* **полностью офлайн**: Chart.js и все ресурсы зашиты внутрь APK (~150 КБ);
* данные — в localStorage самого приложения (отдельно от браузера и PWA);
* резервные копии сохраняются через системный диалог «Сохранить как»,
  восстановление — через выбор файла; GitHub-синхронизация работает;
* 🆕 **перенос данных из браузера — кнопка только в приложении**: при
  первом запуске и после каждого обновления приложение само предложит
  «Загрузить данные из браузера?», а кнопка «📲 Перенос из браузера»
  в «Резервных копиях» доступна в любой момент. Приложение само откроет
  веб-версию с экраном скачивания файла — и переедет ВСЁ: записи, цели,
  события, Секретная папка и даже подключение к GitHub;
* 🆕 **корм v8** (как в веб-версии): история из 3 записей — 🥚 начальный
  (05.10 → 28.10, не считается в «Всего выдано корма»), пачка 1 (09.10 → 18.11),
  пачка 2 (30.10 → 21.12.2026 по консоли CS2); правка дат «действует до»
  отключена — даты подгоняются обновлениями, вручную случайно сбить нельзя;
* Android 7.0+ (лучше 8.0+), подпись приложения — наша собственная.

### Установка через приложение GitHub (с телефона)

1. Открой репозиторий Kopilka в приложении GitHub → раздел **Releases**.
2. Тапни релиз «Копилка для Android — v1.4 🐷 (корм v8, пачка 2 до 21.12)» →
   тапни `KOPILKA-v1.4.apk` → **«Скачать»**.
3. Открой файл из шторки уведомлений («Файлы» → Downloads).
4. Android предупредит про установку из неизвестных источников — разреши.
5. Иконка со свинкой появится на рабочем столе 🐷

⚠️ **Обновление с v1.0**: подпись сменилась (старый ключ не сохранился) —
сначала удали v1.0, потом ставь v1.1. Данные не пострадают: в v1.0 ты их
ещё не заводил, а всё нужное перенесём из браузера.

✅ **Обновление с v1.1 / v1.2 / v1.3 на v1.4**: ставится поверх без удаления (ключ
подписи тот же) — записи, копии и настройки остаются на месте.

### Перенос данных из браузера (PWA) в приложение

Кнопка переноса живёт **только в приложении** — в браузерной версии её
нет (так логичнее: перенос запускается там, куда данные едут).

1. В приложении: «💰 Доход» → «💾 Резервные копии» → **«📲 Перенос из
   браузера»** (или диалог при первом запуске / после обновления).
2. Приложение само откроет Копилку в браузере: там появится экран
   **«📥 Скачать файл переноса»** → тапни → скачается
   `kopilka-transfer_….json` со ВСЕМИ данными.
3. Вернись в приложение → **«📂 Выбрать файл»** → готово: записи, цели,
   события, Секретная папка и подключение к GitHub — всё на месте.
