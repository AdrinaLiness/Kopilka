Копилка — приложение для Android
=================================

Что здесь:
  KOPILKA-v1.0.apk — готовое приложение (Android 7.0+, лучше 8.0+), ~150 КБ
  source/          — исходники: MainActivity.java, манифест, иконка,
                     скрипты сборки и подготовки ассетов

Что это:
  Тот же трекер «Мой трекер / Копилка», что и веб-версия, но в виде
  обычного приложения со свинкой на рабочем столе. Внутри — тот же
  index.html: доход, копилка, корм курицы, накрутка, уровни, секретная
  папка. Работает ПОЛНОСТЬЮ офлайн: Chart.js и все ресурсы зашиты в APK.

  - Данные хранятся в localStorage самого приложения (отдельно от
    браузера/PWA).
  - Резервные копии и файлы Секретной папки сохраняются через системный
    диалог «Сохранить как» (без лишних разрешений).
  - Выбор файлов (восстановление бэкапа, загрузка в хранилище) —
    стандартный системный диалог.
  - GitHub-синхронизация (свой токен) работает как в веб-версии.
  - Портрет и ландшафт, светлая и ночная тема — всё на месте.

Установка (через приложение GitHub, с телефона):
  1. Открой репозиторий Kopilka в приложении GitHub.
  2. Раздел «Releases» → релиз «Копилка для Android — v1.0».
  3. Тапни KOPILKA-v1.0.apk → «Скачать».
  4. Открой файл из шторки уведомлений («Файлы» → Downloads).
  5. Android предупредит про установку из неизвестного источника —
     разреши (стандартно для APK вне Play Market).
  6. Иконка со свинкой появится на рабочем столе 🐷

Перенос данных из браузера/PWA:
  1. В браузерной Копилке сделай резервную копию (настройки → резервные
     копии → скачать JSON).
  2. В APK-версии восстанови её из этого файла.
  3. Готово: вся история, цели и секретная папка переедут в приложение.

Обновление: просто установи новый APK поверх старого (подпись та же) —
данные в localStorage сохранятся.
