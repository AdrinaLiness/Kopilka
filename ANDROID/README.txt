Копилка — приложение для Android
=================================

Что здесь:
  KOPILKA-v1.4.1.apk — готовое приложение (Android 7.0+, лучше 8.0+)
  KOPILKA-v1.4.apk, v1.3, v1.2, v1.1, v1.0 — прошлые версии (остались для истории)
  keystore/        — ключ подписи (пароль в source/build_apk.sh) —
                     нужен, чтобы будущие обновления ставились поверх
  source/          — исходники: MainActivity.java, манифест, иконка,
                     скрипты сборки и подготовки ассетов

Что это:
  Тот же трекер «Мой трекер / Копилка», что и веб-версия, но в виде
  обычного приложения со свинкой на рабочем столе. Внутри — тот же
  index.html: доход, копилка, корм курицы, накрутка, уровни, секретная
  папка. Работает ПОЛНОСТЬЮ офлайн: Chart.js и все ресурсы зашиты в APK.

  - Данные хранятся в localStorage самого приложения (отдельно от
    браузера/PWA).
  - Резервные копии и файлы Секретной папки сохраняются через системный
    диалог «Сохранить как» (без лишних разрешений).
  - Выбор файлов (восстановление бэкапа, загрузка в хранилище) —
    стандартный системный диалог.
  - GitHub-синхронизация (свой токен) работает как в веб-версии.
  - Портрет и ландшафт, светлая и ночная тема — всё на месте.

🆕 НОВОЕ в v1.4.1 — фикс статуса корма:
  Карточка «Статус курицы» показывала старую пачку, когда действуют две
  сразу: «осталось 18 дней» вместо 51. Теперь активным считается самый
  свежий действующий корм — новый перекрывает старый, как слот еды
  в CS2. Веб-версия обновлена тем же фиксом (кэш kopilka-v20).
  Обновление с v1.4 — ставится поверх, данные сохраняются.

Раньше в v1.4 — корм v8 (пачка 2 от 31.10 до 21.12.2026):
  Внутри — тот же index.html, что и в веб-версии на 30.10.2026 (миграция v8):
    - 🥚 начальный корм: 05.10 → 28.10 (не выдавался, в счёт не идёт);
    - пачка 1: 09.10 → 18.11 (40 дней);
    - пачка 2: 31.10 → 21.12.2026 (51 день, Food Expiration по консоли:
      21.12 14:28 UTC). Кривые записи («30.10 → 20.11» и «30.10 → 21.12»,
      дата уточнена на 31.10) исправляются сами при первом запуске.
  Обновление с v1.2/v1.3 — ставится поверх, данные сохраняются.

Раньше в v1.3 — корм v7 (начальный 🥚 + запрет правки дат):
  Внутри — тот же index.html, что и в веб-версии на 30.10.2026:
    - стартовый корм из набора яйца помечен «🥚 начальный» (не удаляется,
      в счёт «Всего выдано корма» не идёт — там только реально выданные);
    - правка дат «действует до» в истории отключена (даты подгоняются
      только обновлениями — вручную случайно сбить нельзя);
    - плюс всё, что пришло в веб-версию ранее (памятник, переносы и т.д.).
  Обновление с v1.2 — ставится поверх, данные в localStorage сохраняются.
  После первого запуска миграция v7 сама подгонит историю корма.

🆕 НОВОЕ в v1.2 — кнопка переноса теперь ТОЛЬКО в приложении:
  В браузерной версии кнопки «Перенос в приложение (Android)» больше
  нет — она там была нелогична. Весь перенос запускается из приложения:
    - при первом запуске и после каждого обновления (как в v1.1);
    - или в любой момент: «💰 Доход» → «💾 Резервные копии» →
      «📲 Перенос из браузера».
  Приложение само откроет Копилку в браузере с экраном «📥 Скачать
  файл переноса» — останется тапнуть кнопку.

  Как получить файл переноса (всё запускается из приложения):
    1. В приложении: «📲 Перенос из браузера» (диалог при запуске
       или кнопка в «Резервных копиях»).
    2. Откроется браузер с Копилкой — тапни «📥 Скачать файл
       переноса». Файл упадёт в Downloads.
    3. Вернись в приложение → «📂 Выбрать файл» → готово.

🆕 НОВОЕ в v1.1 — перенос данных из браузера:
  При ПЕРВОМ запуске и после КАЖДОГО ОБНОВЛЕНИЯ приложение спрашивает:
  «Загрузить данные из браузера?»
    - «📂 Выбрать файл» → выбери kopilka-transfer_….json — и переедет
      ВСЁ: записи, цели, события, шифрованные копии, Секретная папка
      (с ключом) и даже подключение к GitHub (токен, репозиторий).
    - «🌐 Открыть веб-версию» → приложение само откроет Копилку в
      браузере, чтобы скачать файл переноса.
    - «Не сейчас» → больше не побеспокоит до следующего обновления.

  Как получить файл переноса в v1.1 (устарело — см. v1.2 выше):
    1. Открой Копилку в браузере телефона (adrinaliness.github.io/Kopilka).
    2. Вкладка «💰 Доход» → «💾 Резервные копии» →
       «📲 Перенос в приложение (Android)».
    3. Файл скачается в Downloads. Вернись в приложение и выбери его.

  ⚠️ Файл переноса НЕ зашифрован (в нём токен GitHub) — не передавай
  его никому и удали после переноса. Зашифрованные копии 🔐 работают
  как раньше — их импорт через «Резервные копии» внутри приложения.

Установка (через приложение GitHub, с телефона):
  1. Открой репозиторий Kopilka в приложении GitHub.
  2. Раздел «Releases» → релиз «Копилка для Android — v1.4.1 🐷 (фикс
     статуса корма)».
  3. Тапни KOPILKA-v1.4.1.apk → «Скачать».
  4. Открой файл из шторки уведомлений («Файлы» → Downloads).
  5. Android предупредит про установку из неизвестного источника —
     разреши (стандартно для APK вне Play Market).
  6. Иконка со свинкой появится на рабочем столе 🐷

⚠️ Обновление с v1.0 на v1.1:
  Подпись сменилась (старый ключ сборки не сохранился), поэтому Android
  не поставит v1.1 поверх v1.0. Сначала удали приложение v1.0, затем
  ставь v1.1 — и перенеси данные из браузера (приложение само спросит).

Обновления внутри линейки v1.1+:
  Keystore теперь хранится в keystore/ (пароль — в build_apk.sh), так
  что следующие версии встанут поверх без удаления, а localStorage
  сохранится. Обновления (v1.1 → v1.2 → v1.3 → v1.4 → v1.4.1) ставятся поверх без удаления.

Сборка из исходников (Linux, без Gradle):
  1. android-sdk: build-tools r34 (→ android-14/), platform-34
     (→ android-34/), JDK 17 (→ jdk-17…/).
  2. python3 source/build_assets.py   # ассеты + иконка + проверка JS
  3. bash source/build_apk.sh         # javac + d8 + aapt2 + apksigner
